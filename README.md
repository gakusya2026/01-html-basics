## 💡 初心者に伝えたいHTMLの3大ルール

1. **タグは「開いて閉じる」のが基本**
   - `<p>`こんにちは`</p>` のように、挟み込むことで「ここからここまでが段落」とブラウザに伝えます。
   - 例外: `<img>` や `<hr>` のように、中身を挟まないタグは閉じタグが不要です。
2. **「入れ子（親子関係）」とインデント（字下げ）**
   - タグの中に別のタグを入れることを「入れ子」と呼びます。
   - 内側のタグには半角スペース2つ（またはTab）の字下げを入れると、コードがぐっと読みやすくなります。
3. **ファイル保存（Ctrl+S / Cmd+S）とブラウザ更新（F5 / Cmd+R）**
   - コードを書き換えたら「保存 → ブラウザ再読み込み」で変化を確認するリズムを掴みましょう。

## 🏷️ セマンティクスHTML（意味を持つタグ）一覧

単に見た目を作るだけでなく、**タグが持つ「意味（セマンティクス）」** に合わせて適切なタグを選びます。

| タグ名 | 意味（役割） | 口頭での説明例 |
| :--- | :--- | :--- |
| `<!DOCTYPE html>` | 文書型の宣言 | 「このファイルは最新のHTML5で書かれていますという宣言です」 |
| `<html lang="ja">` | HTML文書のルート | 「日本語で書かれたWebページの全体を囲む大枠です」 |
| `<head>` | ページの設定情報 | 「タイトルや文字コードなど、画面には出ない設定を書く場所です」 |
| `<body>` | ページの本体 | 「ブラウザの画面に実際に表示される内容はすべてここに書きます」 |
| `<header>` | 導入部・ヘッダー | 「ページの一番上にあるタイトルや看板エリアです」 |
| `<nav>` | ナビゲーション | 「ページ内の移動メニュー（目次）を置く場所です」 |
| `<main>` | 主要コンテンツ | 「このページのメインとなる中心情報です（1ページに1つ）」 |
| `<section>` | コンテンツのまとまり | 「テーマごとの区切りです。必ず見出し（h2など）とセットで使います」 |
| `<h1>` | 最重要見出し（大見出し） | 「ページの主題です。原則1ページに1回だけ使います」 |
| `<h2>` | 小見出し（中見出し） | 「各セクションのタイトルです」 |
| `<p>` | 段落（テキスト） | 「普通の文章を書くときに使います」 |
| `<ul>` と `<li>` | 箇条書きリスト | 「・がつく箇条書きです。メニュー一覧などに便利です」 |
| `<a>` | リンク（アンカー） | 「クリックすると別の場所や別ページへジャンプします」 |
| `<img>` | 画像 | 「画像を表示します。srcでファイル名、altで説明文を指定します」 |
| `<hr>` | 水平線・区切り線 | 「話題が変わるところに引く区切り線です」 |
| `<footer>` | 終了部・フッター | 「ページの一番下にあるコピーライトや著作権情報の場所です」 |
| `<small>` | 注釈・著作権表示 | 「免責事項やコピーライト（©）などの小さな注記です」 |

## 🔍 つまずきやすいポイントの詳しい解説

### 1. ページ内リンク（`href="#about"` と `id="about"`）の仕組み
メニューの「お店について」をクリックすると、同じページの下部にある「お店について」へジャンプします。

```text
【クリックする側】
<a href="#about">お店について</a>
         ↑
         「#about という名前の場所へ飛んで！」

【ジャンプ先の目的地】
<section id="about">
         ↑
         「私の名前は about です！」
```
> **💡 ポイント**: `#` は「同じページ内のIDを探す記号」です。

### 2. 画像の読み込み（相対パスと `alt` 属性）
```html
<img src="coffee.jpeg" alt="当店自慢のコーヒーの画像" width="300" height="200">
```
- **`src="coffee.jpeg"`（画像ファイルの場所）**: `index.html` と **同じフォルダ** に画像があるため、ファイル名だけで直接読み込めます。
- **`alt="当店自慢のコーヒーの画像"`（代替テキスト）**: 通信エラーで画像が出ないときや、視覚障がい者向けの音声読み上げソフトが読めるように、何の写真かを言葉で説明しておきます。
